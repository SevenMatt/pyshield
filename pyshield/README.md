# PyShield FERRAMENTA EDUCACIONAL

Scanner antimalware simples em Python. Projeto **educacional/defensivo** — não substitui um antivírus comercial.

## Instalação
pip install -r requirements.txt

## Uso
python pyshield.py C:\\ --quarantine quarantine --vt-key SUA_CHAVE
python pyshield.py C:\\Users --delete   # cuidado: apaga de verdade

## Aviso
Use apenas no SEU computador ou em máquinas que você tem autorização para analisar.
